# MARK Hospitals HMS

This is a React/Vite app that runs the supplied MARK Hospitals dashboard. The original dashboard is kept intact in `public/hospital-dashboard.html`, hosted by the React app so its existing portals, demo data, and interactions continue to work.

## Run locally

1. Install Node.js (18 or newer).
2. Install dependencies:

   ```sh
   npm install
   ```

3. Start the development server:

   ```sh
   npm run dev
   ```

4. Open the local URL printed by Vite.

Create a production build with `npm run build`; preview it with `npm run preview`.

## Demo access

Click **Continue** on the login screen to enter directly as Administrator. This is demo-only access without authentication, not suitable for production.
